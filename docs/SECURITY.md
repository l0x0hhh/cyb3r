# 安全与公开边界

管理员密码使用随机盐 scrypt 哈希，校验使用恒定时间比较；旧哈希可在验证后升级。登录失败按用户名与 IP 组合、账户和 IP 分别限制，达到阈值时返回 429。会话及失败计数持久化，登录 Cookie 使用 HttpOnly、SameSite，HTTPS 下使用 Secure。

访客标识用于关联本浏览器的记录，不作为身份验证。姓名和完整手机号查询与归还校验仍然保留；公开记录脱敏。偏好 Cookie 仅存白名单字段。

EMAIL_CONFIG_KEY 用于加密 SMTP 配置中的凭证；生产自行生成，备份时与数据库一起妥善保护。不得复用开发默认密钥。生产启动需要管理员密码哈希或兼容密码配置，推荐只使用 ADMIN_PASSWORD_HASH。

源码中存在可重现测试用的合成姓名、号码、密码、哈希与本地 SMTP 夹具，不是生产数据。非生产开发默认值仅用于兼容原项目，不应作为部署凭证。

公开仓库不包含旧 Git 历史、环境文件、数据库、访客与借用人资料、真实上传照片、二维码、密钥、生产备份、运维日志和内部上线报告。服务器配置模板仅含通用示例。
